# Church Service Transcriber

Download church services from YouTube, transcribe them locally with Whisper, organise them into sections with your local Ollama model, translate, edit and export.

![Supports amd64](https://img.shields.io/badge/amd64-yes-green.svg) ![Supports aarch64](https://img.shields.io/badge/aarch64-yes-green.svg)

See the **Documentation** tab for setup.
