# Church Service Transcriber

Download church services from YouTube, transcribe them locally with Whisper, organise them into sections and sermon notes with your local Ollama model, then edit, translate, export and use them in automations.

![Supports amd64](https://img.shields.io/badge/amd64-yes-green.svg) ![Supports aarch64](https://img.shields.io/badge/aarch64-yes-green.svg)

**Before installing:** the default Whisper model (`large-v3-turbo`) needs about **6 GB of RAM for the Home Assistant VM** and 4+ vCPUs. Smaller models need less - see the **Documentation** tab for the full table.
